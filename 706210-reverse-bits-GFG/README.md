# [Reverse Bits](https://www.geeksforgeeks.org/problems/reverse-bits-1611130171/1)
## Easy
Reverse the bits of a given non-negative integer n and return the number obtained after reversal. No leading zeros are to be considered during reversal.
&nbsp;
Examples:
Input: n = 11
Output: 13
Explanation: (11)10 = (1011)2, After reversing the bits we get: (1101)2 = (13)10.
Input: n = 10
Output: 5
Explanation: (10)10 = (1010)2, After reversing the bits we get: (0101)2 = (101)2 = (5)10.
Constraints :
1 ≤ n ≤ 109
